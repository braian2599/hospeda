   959→### Bug CRÍTICO encontrado y fixeado: Homepage en blanco
   960→
   961→**Síntoma:** La homepage (http://localhost:81/) renderizaba solo el logo de Z.ai en una pantalla blanca. El contenido React no se montaba.
   962→
   963→**Causa raíz:** En `src/app/page.tsx`, había 8 instancias de patrones HTML inválidos que causaban errores de hidratación de React:
   964→1. `<button onClick={...}><Button>...</Button></button>` — botón anidado dentro de botón (3 instancias)
   965→2. `<Link href="..."><Button>...</Button></Link>` — Link envolviendo Button que también es `<button>` (5 instancias)
   966→
   967→React no permite elementos `<button>` anidados porque es HTML inválido. Esto causaba el error:
   968→```
   969→[error] In HTML, %s cannot be a descendant of <%s>.
   970→This will cause a hydration error.%s <button> button
   971→```
   972→
   973→**Fix aplicado:**
   974→1. Reemplazado `<Link><Button>...</Button></Link>` → `<Button asChild><Link>...</Link></Button>` (5 instancias)
   975→   - El patrón `asChild` usa `@radix-ui/react-slot` para fusionar el Link con los estilos del Button, renderizando un solo `<a>` con clases de botón
   976→2. Reemplazado `<button onClick={...}><Button>...</Button></button>` → `<Button onClick={...}>...</Button>` (3 instancias)
   977→   - Eliminado el wrapper `<button>` redundante, el onClick se movió directamente al Button
